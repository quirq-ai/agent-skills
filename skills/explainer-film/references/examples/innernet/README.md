# The reference film: Innernet field guide

A 2:49 explainer for Innernet (a personal search engine and encyclopedia of the folders on
one machine), narrated by Lily. Its full source is `film/` in quirq-ai/innernet; these are
copies of the parts most worth reading before writing a film of your own.

| File | Read it for |
| --- | --- |
| `BRIEF.md` | a filled brief: message, chapters, the requester's words, assets, notes |
| `STORYBOARD.md` | a filled storyboard: the spine, bans, truthfulness, seams, every frame |
| `film.mjs` | 21 frames in three chapters, with counters, plates and pause tuning |
| `script.mjs` | the narration, and the `SAY` respellings the hearing check forced |
| `music-plan.mjs` | the music plan: swells on the cards, a privacy close-in, dusk and dawn |
| `scenes/07-stays-on-your-machine.mjs` | a plate scene with a seal and the HUD padlock |
| `scenes/09-innerpedia.mjs` | a real screen in a mount, a whip cut, callouts on words |
| `scenes/15-one-command.mjs` | typing a command, its output, and the counter ticking |
| `scenes/21-close.mjs` | the close: a callback, a wordmark, a tagline on words, a credit |

Two of the scenes import helpers from that film (`_tree.mjs`, `_addsite.mjs`) that
read its index, so they do not run here. They are examples of the contract in
`template/src/ENGINE.md`, not code to copy whole.
